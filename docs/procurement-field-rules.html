ANAGROCI PROCUREMENT - FIELD RULES: HOW EACH FIELD IS FILLED, WHAT IS MANDATORY, ALLOWED LIMITS.
How it is filled: Text = user types it. Drop-down = user picks from a list. Auto = fills itself. Suggested = portal proposes, user confirms. Calculated = portal works it out, user cannot type it.
"A → B" = today it is A, we will change it to B.   Warn = user can still save after confirming.   Stop = cannot be saved (only a few checks against the masters and the drying ledger; a typed value on its own is never stopped, only warned about).
